# Enterprise RAG Platform

AI-powered Retrieval-Augmented Generation (RAG) platform built using ASP.NET Core, OpenAI APIs, semantic search, and vector databases.

---

## Features

- Semantic document search
- AI-powered contextual responses
- Vector embedding generation
- OpenAI integration
- REST API architecture
- Document ingestion pipeline
- Context-aware retrieval
- Scalable backend architecture
- Docker support

---

## Tech Stack

### Backend
- ASP.NET Core
- C#
- REST APIs

### AI/LLM
- OpenAI API
- Embeddings
- RAG Pipeline

### Database
- PostgreSQL / MongoDB
- Vector Database
- Redis

### DevOps
- Docker
- Docker Compose

---

## Architecture

User Query
    ↓
API Layer
    ↓
Embedding Search
    ↓
Vector Database
    ↓
Context Retrieval
    ↓
OpenAI LLM
    ↓
Generated Response
